💡 Linux Display Server Requirement:

ClipSync requires a clipboard listener. Install wl-clipboard if you use Wayland, or xclip if you use X11. Check with echo $XDG_SESSION_TYPE.

Quick Terminal Setup by Distro:

Ubuntu / Debian / Linux Mint
$sudo apt install -y libx11-dev libwayland-dev libxkbcommon-dev libvulkan-dev wl-clipboard xclip $sudo dpkg -i clipsync-linux.deb
Fedora / RHEL / CentOS
$sudo dnf install -y libX11-devel libwayland-dev libxkbcommon-dev vulkan-headers wl-clipboard xclip
Arch Linux / Manjaro / EndeavourOS
$sudo pacman -S --needed libx11 libwayland-dev libxkbcommon-dev libvulkan-dev wl-clipboard xclip
