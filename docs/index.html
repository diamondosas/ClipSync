Core Capabilities

Built for Speed, Privacy, and Zero Friction

ClipSync eliminates accounts, cloud relays, and telemetry. Everything travels directly over your local subnet.

⚡
Sub-10ms Speed

Instant Local LAN Synchronization

High-performance transport powered by KCP over raw UDP sockets delivers instantaneous clipboard handoff across devices on the same Wi-Fi router.

Protocol: KCP / UDP Payload: AES-128 Encrypted Latency: < 5ms average
📡
Zero Config

mDNS Auto-Discovery

No IP typing or pairing codes. ClipSync broadcasts presence over _clipsync._tcp and automatically links active machines.

UDP Multicast: 224.0.0.251:5353

How It Works

Encrypted Peer-to-Peer Protocol

Direct, socket-level communication without intermediary servers or external routing.

Transport Layer KCP / UDP Low-latency reliable packet streaming with minimal overhead
Data Port UDP 9999 Encrypted clipboard payload stream and bidirectional heartbeat
Service Discovery mDNS / UDP 5353 Automatic multicast Zeroconf peer detection on local subnet
Payload Security AES Block Cipher End-to-end encrypted packet stream for all clipboard data
