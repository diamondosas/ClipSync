Core Features

Why Developers & Users Choose ClipSync

A native, lightning-fast clipboard companion built without cloud compromises.

⚡

Instant LAN Sync

Sub-10ms clipboard synchronization using high-performance KCP over UDP sockets.

🔒

Zero Cloud & 100% Private

No accounts, no telemetry, no relays. Your clipboard data never leaves your local Wi-Fi.

📡

Automatic Discovery

Zero manual setup. ClipSync announces presence on _clipsync._tcp and auto-pairs active peers.

📌

Clipboard History & Pinning

Search previous clips, pin essential snippets to top, and clear unpinned text in one tap.

🪶

Ultra Low Footprint

Written in Go with native GUI bindings. Requires only ~15 MB RAM and ~0.1% background CPU.

💻

Cross Platform

Seamlessly share clipboard text between Windows, macOS, Linux (X11 & Wayland), and Android.

How It Works

Encrypted Peer-to-Peer Protocol

ClipSync communicates directly between devices on your local network using AES-128 encryption.

Transport KCP / UDP Low-latency reliable packet streaming
Default Port UDP 9999 Encrypted clipboard data & heartbeat
Discovery mDNS / UDP 5353 Zeroconf auto device detection
Security AES Block Cipher End-to-end encrypted packet stream
