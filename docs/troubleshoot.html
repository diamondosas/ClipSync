Troubleshooting & Common Problems

Quick, verified solutions for firewall ports, Linux display servers, Android background sync, and network configuration.

No troubleshooting guides matching your search query. Try searching for firewall, wayland, or android.

ClipSync relies on mDNS / Zeroconf (UDP Port 5353) for discovery and KCP (UDP Port 9999) for encrypted data transport. If your devices do not see each other in the Devices tab:

A. Allow UDP Ports in OS Firewall

Linux (UFW Firewall)
$sudo ufw allow 9999/udp && sudo ufw allow 5353/udp $sudo ufw reload
Windows (PowerShell as Administrator)
PS>New-NetFirewallRule -DisplayName "ClipSync UDP Ports" -Direction Inbound -LocalPort 9999,5353 -Protocol UDP -Action Allow
macOS
Open System Settings > Network > Firewall and ensure incoming connections are allowed for ClipSync.

B. Check Wi-Fi Router "AP Isolation" / "Guest Mode"

Many Wi-Fi routers (especially Guest networks and public Wi-Fi) enable AP Isolation / Client Isolation, which prevents connected devices on the same Wi-Fi from talking to each other directly.

Fix: Connect both devices to your primary home/office Wi-Fi network and ensure AP Isolation is turned OFF in your router settings.

On Linux, ClipSync monitors the operating system clipboard through standard display server tools. If copied text on Linux does not trigger a sync, install the proper tool for your environment:

Step 1: Check your display server type

Terminal
$echo $XDG_SESSION_TYPE

Step 2: Install the matching clipboard tool

  • If output is wayland:
    Wayland Tool
    $sudo apt install wl-clipboard # Ubuntu/Debian $sudo dnf install wl-clipboard # Fedora $sudo pacman -S wl-clipboard # Arch
  • If output is x11:
    X11 Tool
    $sudo apt install xclip # Ubuntu/Debian $sudo dnf install xclip # Fedora $sudo pacman -S xclip # Arch

Starting with Android 10 (API 29), the Android operating system strictly prohibits background applications from silently modifying or reading the system clipboard to prevent malicious apps from stealing passwords or private data.

How to use ClipSync on Android:

  1. When you copy text on your computer, ClipSync on Android receives it in the background and logs it in your Clipboard History.
  2. Open ClipSync on your phone and tap COPY on any card to place it into the Android system clipboard.
  3. You can now paste it into WhatsApp, Gmail, Chrome, or any app.

Keep Background Discovery Alive:

To prevent Android OS from putting ClipSync to sleep when the screen is locked: Go to Android Settings > Apps > ClipSync > Battery > Set to "Unrestricted".

If you downloaded the generic clipsync-linux.tar.gz archive on a minimal Linux installation, make sure the graphical runtime libraries are installed:

Debian / Ubuntu / Linux Mint
$sudo apt install -y libx11-dev libx11-xcb-dev libwayland-dev wayland-protocols libxkbcommon-dev libxkbcommon-x11-dev libvulkan-dev libegl-dev libgles2-mesa-dev libxcursor-dev libxi-dev libxrandr-dev libxinerama-dev libxxf86vm-dev libxfixes-dev libgtk-3-dev libayatana-appindicator3-dev
Fedora / CentOS / RHEL
$sudo dnf install -y libX11-devel libwayland-dev libxkbcommon-dev vulkan-headers libayatana-appindicator3-devel gtk3-devel

ClipSync uses a single-instance lock to ensure multiple background listeners don't collide on port 9999.

When you close the application window, ClipSync does not quit; it minimizes to your system notification tray so that clipboard synchronization continues in the background uninterrupted.

  • To show the window: Click the ClipSync icon in your Windows Taskbar System Tray, macOS Menu Bar, or Linux Tray.
  • To completely exit: Right-click the ClipSync tray icon and click Quit.
  • Force kill if stuck (Linux/macOS): Run killall clipsync in your terminal.
