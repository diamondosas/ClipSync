This is the setup from the [Gio Android docs](https://gioui.org/doc/install/android?utm_source=gemini), with a Java host app around it.

## Prerequisites

* **Go and gogio:** `go install gioui.org/cmd/gogio@latest`
* **Android SDK & NDK:** Android SDK with the NDK bundle installed, and `ANDROID_SDK_ROOT` pointing to the SDK root. Install the NDK via `sdkmanager ndk-bundle`. If your `sdkmanager` no longer lists `ndk-bundle`, install a versioned one:
```bash
sdkmanager --list | grep ndk

```


* **JDK:** The docs note that `gogio` requires OpenJDK 8 and newer Java versions can break it. Try your current JDK first. If `gogio` fails, set `JAVA_HOME` to JDK 8 for that build command, and use a newer JDK for Gradle.

## 1. Go side

Initialize the module:

```bash
mkdir -p workspace/gioapp && cd workspace/gioapp
go mod init example.com/gioapp

```

Create `main.go` (written for Gio v0.7 or newer):

```go
package main

import (
	"log"
	"strconv"

	"gioui.org/app"
	"gioui.org/font/gofont"
	"gioui.org/layout"
	"gioui.org/op"
	"gioui.org/text"
	"gioui.org/unit"
	"gioui.org/widget"
	"gioui.org/widget/material"
)

func main() {
	go func() {
		// No os.Exit here: it would kill the whole Java app when the
		// Gio screen closes. Looping lets the screen be opened again.
		for {
			w := new(app.Window)
			if err := run(w); err != nil {
				log.Println("gio window closed:", err)
			}
		}
	}()
	app.Main()
}

func run(w *app.Window) error {
	th := material.NewTheme()
	th.Shaper = text.NewShaper(text.WithCollection(gofont.Collection()))

	var (
		ops   op.Ops
		btn   widget.Clickable
		count int
	)

	for {
		switch e := w.Event().(type) {
		case app.DestroyEvent:
			return e.Err
		case app.FrameEvent:
			gtx := app.NewContext(&ops, e)
			if btn.Clicked(gtx) {
				count++
			}
			layout.Center.Layout(gtx, func(gtx layout.Context) layout.Dimensions {
				return layout.Flex{Axis: layout.Vertical, Alignment: layout.Middle}.Layout(gtx,
					layout.Rigid(material.H4(th, "Hello from Gio").Layout),
					layout.Rigid(layout.Spacer{Height: unit.Dp(16)}.Layout),
					layout.Rigid(material.Button(th, &btn, "Clicked "+strconv.Itoa(count)).Layout),
				)
			})
			e.Frame(gtx.Ops)
		}
	}
}

```

Fetch dependencies and verify:

```bash
go mod tidy
go run . # test on desktop (exit with Ctrl+C)

```

## 2. Build the AAR

```bash
export ANDROID_SDK_ROOT=$HOME/Android/Sdk
export PATH=$PATH:$(go env GOPATH)/bin

cd workspace/gioapp
gogio -target android -buildmode archive \
      -appid com.example.gioapp \
      -o ../JavaApp/app/libs/gioapp.aar .

```

* `-buildmode archive` generates an `.aar` bundle ready for Android Studio.
* Add `-arch arm64` during development to speed up compilation by building only one architecture.
* Keep `-appid` distinct from your Java app's `applicationId`.

## 3. Java side

Create an Android Studio project (**Java**, **Empty Views Activity**), then configure the following files:

### `app/build.gradle`

```groovy
plugins { 
    id 'com.android.application' 
}

android {
    namespace 'com.example.javaapp'
    compileSdk 34

    defaultConfig {
        applicationId "com.example.javaapp"
        minSdk 21          // Raise if manifest merger conflicts occur
        targetSdk 34
        versionCode 1
        versionName "1.0"
    }

    compileOptions {
        sourceCompatibility JavaVersion.VERSION_1_8
        targetCompatibility JavaVersion.VERSION_1_8
    }
}

dependencies {
    implementation files('libs/gioapp.aar')
}

```

### `app/src/main/AndroidManifest.xml`

Declare `org.gioui.GioActivity`, GLES 3 support, and the Gio theme:

```xml
<manifest xmlns:android="http://schemas.android.com/apk/res/android">

    <uses-feature android:glEsVersion="0x00030000" android:required="true"/>

    <application
        android:label="JavaApp"
        android:theme="@android:style/Theme.Material.Light.NoActionBar">

        <activity 
            android:name=".MainActivity" 
            android:exported="true">
            <intent-filter>
                <action android:name="android.intent.action.MAIN"/>
                <category android:name="android.intent.category.LAUNCHER"/>
            </intent-filter>
        </activity>

        <activity
            android:name="org.gioui.GioActivity"
            android:exported="false"
            android:theme="@style/Theme.GioApp"
            android:configChanges="orientation|keyboardHidden"
            android:windowSoftInputMode="adjustResize"/>
    </application>
</manifest>

```

### `app/src/main/java/com/example/javaapp/MainActivity.java`

```java
package com.example.javaapp;

import android.app.Activity;
import android.content.Intent;
import android.os.Bundle;
import android.widget.Button;

public class MainActivity extends Activity {
    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        
        Button btn = new Button(this);
        btn.setText("Open Gio screen");
        btn.setOnClickListener(v ->
            startActivity(new Intent(this, org.gioui.GioActivity.class))
        );
        
        setContentView(btn);
    }
}

```

## 4. Compile to APK

Run from the `JavaApp` directory:

```bash
./gradlew assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk

```

*(Or select **Run** in Android Studio. For production builds, run `./gradlew assembleRelease` configured with signing keys).*

### Standalone APK (Without Java Wrapper)

If you do not need the Java wrapper, build a standalone APK directly with `gogio`:

```bash
gogio -target android -appid com.example.gioapp -o gioapp.apk .
adb install gioapp.apk

```

## Common problems

* **`ANDROID_SDK_ROOT` or NDK not found:** Verify the environment variable points to your SDK root and that the NDK is installed inside `$ANDROID_SDK_ROOT/ndk/` or `$ANDROID_SDK_ROOT/ndk-bundle/`.
* **Manifest merger error on `minSdk`:** Increase `minSdk` in `app/build.gradle` to match the minimum API version requested by the generated AAR.
* **Go changes not reflecting:** Android Studio will not rebuild the AAR automatically. Re-run the `gogio` command, sync Gradle, and trigger a project rebuild.
* **Emulator crashes or blank screen:** Ensure OpenGL ES 3.0+ emulation is enabled in the emulator settings, or deploy directly to a physical device.

*Note: The reopen loop relies on the behavior of Gio's Android backend lifecycle. If reopening the Gio activity misbehaves on your test target, verify log output via `adb logcat -s GoLog`.*
